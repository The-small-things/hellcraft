# Phase 3 screenshots

Taken by the client game tests (`versions/26.3/src/gametest`, `bash tools/dev/clienttest.sh`) on the Phase 3 test
build (commit d81ebdf), before the first play session's fixes. The number is the order they were taken in:

- `join`, `hud`, `inventory`: joining a server, the blood hearts and the blood items.
- `rig_*`, `minos_*`, `cerberus_*`, `plutus_*`, `phlegyas_*`, `monsters_*`: every model and animation (BossTest).
- `map_*`: the map from the air; `nav_*`: the circle card, compass, Map of Hell and Journal.
- `castle_*`: the Noble Castle and a shade's trades; `piece_*`: the set-pieces; `layer_*`: each circle's rule.
- `fight_*`, `cerberus_fight_*`, `plutus_fight_*`, `phlegyas_fight_*`: the guardian fights in their lairs, with
  their danger marks; `ferry_*`: the ferry across the Styx to Dis.
